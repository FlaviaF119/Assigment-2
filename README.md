App for accomodations types by municipality
Target audience: tourists
Research question: What are the types of accomodations by municipality?
In the app a user can choose a municipality and types of accomodations offered by that municipality. 
One limitation of the app is that it doesn't show the prices of the different accomodations so it can't be used to compare the municipalities.
We used ChatGpt to get help with the code because we needed to extract the information regarding Municipality and Accomodations type and create two new columns. We also used it to get help help creating the app and managing the errors.
